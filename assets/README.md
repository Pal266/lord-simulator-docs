# Lord Simulator Visual Assets

This directory contains visual source assets and visual reference material used by Lord Simulator specifications and design work.

Asset organization and visual-production rules are defined in `standards/VISUAL_STANDARD.md`.

Subdirectories should be created only when they are needed. Expected categories may include UI assets, textures, models, materials, icons, branding, and reference material.

Production assets intended for implementation must be clearly distinguishable from concept, mood, style, or other reference material. Reference-only material belongs under `assets/references/` when that category is introduced.

Large binary assets must not be added in quantity until the project has established an appropriate binary-asset storage strategy.
